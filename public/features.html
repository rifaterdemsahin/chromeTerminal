✨ chromeTerminal features

A browser chrome over a real macOS shell. The live PTY only runs on http://127.0.0.1:3847 after npm start. This page is static, so it also works on GitHub Pages.

🖥️ Shell

  • xterm.js in the page, Node node-pty + WebSocket on localhost.
  • Login zsh (or $SHELL), cwd starts in your home directory.
  • Each browser tab is its own session. 🆕 New session opens another tab.
  • Sessions park for ~30 minutes if you leave the tab, then resume when you come back.
  • Hidden-tab resizes are ignored so the PTY does not collapse to a tiny size.
  • 🔄 Reconnect starts a fresh shell. Double Ctrl+C (within 800ms) leaves the session on purpose.
  • 🏷️ Badge — iTerm-style watermark in the terminal (this tab). Type a label, ✅ Set or Enter. Home / Projects / project chips / grok / agy update it so you can see where you are. 🚫 Clear hides it.

📁 Projects

  • 🏠 Home / 📁 Projects — cd to $HOME or ~/projects.
  • Chip row of every folder in ~/projects (local server only).
  • 🔍 Filter by name.
  • 🕒 Latest — last modified first. 🔤 A–Z — name order. Choice is saved.

▶️ Run & keys

  • 🤖 grok / ✨ agy — type the command and Enter.
  • 📋 ls5 — newest 5 directory entries.
  • 1️⃣ 2️⃣ 3️⃣ 4️⃣ — send that number and Enter (for “pick 1–4” prompts).
  • ⇥ Tab / ⇤ Shift+Tab — send those keys into the PTY.
  • 💾 Save — download the terminal buffer as .txt.
  • 📤 Commit · push · leave — git add -A, commit with your message, git push origin HEAD. On success it waits 8 seconds so you can read the log, then the session closes. On failure it stays open. Run this at a shell prompt, not inside grok/agy.

🔒 Safety

  • Bound to 127.0.0.1. Do not publish the PTY server.
  • Optional TERMINAL_TOKEN query param.
  • GitHub Pages is docs + UI preview only — no Mac shell.

🚀 Run

npm install && npm start then open Chrome at http://127.0.0.1:3847.

♻️ Auto-restart

  • npm start runs scripts/keep-alive.js, which spawns server.js on 127.0.0.1:3847.
  • If the process exits, the keeper starts it again (backoff 0.8s up to 15s).
  • Every 4s it hits /health. If the port is down after a 2.5s start grace, it kills the child and relaunches.
  • Ctrl+C on the keeper stops both processes.
  • No keeper: npm run server. Reload-on-edit: npm run dev.
