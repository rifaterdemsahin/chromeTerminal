📖 chromeTerminal guide

What this is

chromeTerminal is a web UI (xterm.js) that talks to a small Node server on your Mac. The server opens a real PTY and runs your login shell (zsh). Keystrokes go over a WebSocket; output comes back into the page. It is your machine, not a cloud terminal.

Where it works

  • Live shell: only on this computer at http://127.0.0.1:3847 while npm start is running. Bound to localhost on purpose.
  • GitHub Pages: https://rifaterdemsahin.github.io/chromeTerminal/ — static copy of this page and this guide. Pages cannot run Node, cannot spawn zsh, and cannot see ~/projects.

How to run the real terminal

git clone https://github.com/rifaterdemsahin/chromeTerminal.git
cd chromeTerminal
npm install
npm start
open -a "Google Chrome" http://127.0.0.1:3847

Auto-restart: npm start is a keeper (scripts/keep-alive.js). If the Node process dies or port 3847 stops answering /health, it starts server.js again (backoff 0.8s–15s). Ctrl+C stops the keeper and the server. One-shot without restart: npm run server. To start at macOS login: npm run macos-install (LaunchAgent com.rifaterdemsahin.chrometerminal). Remove with npm run macos-uninstall.

Top menu

  • 📖 Guide — this panel.
  • ✨ Features — full list on features.html.
  • 🍎 Login — start at macOS login: macos-start.html (npm run macos-install).
  • ⛶ Fullscreen — fill the display (Esc to leave). 📦 Collapse all hides About/Menu/Theme/Badge/Projects. 📂 Expand all shows them. 🧘 Focus toggles the same. The Panels row toggles each strip; that state is saved.
  • 🏠 Home / 📁 Projects — cd to your home or ~/projects. ↩️ Last project — cd ~/projects, run ls -ant, then cd into the newest folder.
  • Project chips — one click cd into a repo (local server only); clicking automatically moves the active project to the left and saves the order. 🕒 Latest sorts by folder modified time; 🔤 A–Z is name order.
  • 🤖 grok / 🎭 claude / ✨ agy — launches Grok (grok --effort medium --permission-mode acceptEdits), Claude (claude --model sonnet --effort medium --dangerously-skip-permissions), or Antigravity (agy --effort medium --mode accept-edits) directly in medium reasoning effort.
  • 📚 Prompts — title bar, next to 💾 Save. Library of reusable prompts. Insert or Send into the PTY. Add your own (saved here). Built-ins are in public/prompts.json.
  • 📋 ls5 — newest 5 directory entries (ls -ant, skip the total line, first 5).
  • ⏱ Session time — in the title bar, hours and minutes this shell has been on (from when the PTY started; reconnects keep the same clock).
  • 💾 Save — download the visible terminal buffer as a .txt file.
  • 🎤 Dictate — focuses the shell cursor, then starts Chrome voice typing into the PTY. Click again to stop. After the cursor is in the terminal you can also double-tap Fn (Globe) for macOS Dictation.
  • 1️⃣ 2️⃣ 3️⃣ 4️⃣ — send that number and Enter when a prompt asks you to pick.
  • ⇥ Tab / ⇤ Shift+Tab — send those keys (handy in grok/agy pickers).
  • Ctrl+C, Ctrl+C — two interrupts within 800ms disconnect this session (get out). A single Ctrl+C still goes to the shell.
  • 🎨 Theme — pick a palette (saved in this browser). Native: 🤖 Grok Night (Grok TUI magenta/dark), 🌤️ Grok Day, ✨ Antigravity (agy Solarized Dark — error/warn/ok lint colors). The ● error/warn/ok/info chips show those ANSI colors.
  • 🏷️ Badge / pwd — the title bar shows the live shell working directory. The watermark tracks that path (short ~ form). You can still Set a label; the next cd updates both again.
  • 🧠 Second Brain — dedicated panel to launch AI agents (agy, grok, claude) directly in /Users/rifaterdemsahin/secondbrain-azurefiles/secondbrain/, run pap (Pull · Push · Archive) sync workflow, and launch the local dashboard on port 8899.
  • 🧪 Testing — diagnostics panel with Internet Speed test, AI API model reachability probes (Gemini, Claude, OpenAI, Grok, OpenRouter, Ollama), and infrastructure health checks for proxmox.rifaterdemsahin.com and n8n.rifaterdemsahin.com with detailed modal popups.
  • ⚡ Speed & Quality — title bar badge and button. Displays live ping, DNS resolution latency, bandwidth speed, and overall connection quality score. Click to open the detailed modal popup with route pings (local, Cloudflare, Google), full DNS lookup metrics, and on-demand download speed tests.
  • 📤 Commit · push · leave — at a shell prompt: git add -A, commit, git push. When push succeeds, wait 8 seconds (so you can read the output), then this session closes. If commit/push fails, you stay connected.

Why Pages is not a remote Mac

GitHub Pages only serves HTML, CSS, and JS. The PTY lives in server.js. Do not bind the server to 0.0.0.0 or put it on the public internet. Optional: TERMINAL_TOKEN=secret npm start then ?token=secret.
